# Unidade 1: Fundamentos de Data Analytics, Dados Abertos e CRISP-DM

Esta unidade introduz o ecossistema de análise de dados e a metodologia CRISP-DM através de um problema real de negócio.

---

## Escopo da Unidade

* **Abordagem Teórica**: Introdução ao ecossistema de dados, portais de dados abertos e o ciclo de vida de projetos com CRISP-DM.
* **Formulação de Hipóteses**: Definição da lógica de negócio para a criação do alvo binário `acidente_fatal`.

---

## Materiais Disponíveis

* **Aula 1 - Analise de Dados - Fundamentos de Data Analytics**: Conteúdo interativo e conceitos iniciais.
* **Dados_PRF_2025**: Arquivo CSV original com a base bruta da Polícia Rodoviária Federal.
* **ArquivoTXT**: Notas técnicas e documentação complementar de suporte.
* **Atividades_Excel**: Exercícios iniciais para os primeiros insights visuais.
