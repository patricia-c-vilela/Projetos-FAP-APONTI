# Unidade 2: Excel para Análise de Dados

Esta unidade aborda a exploração visual e o tratamento inicial de arquivos tabulares utilizando planilhas eletrônicas.

---

## Escopo da Unidade

* **Exploração Inicial**: Técnicas de importação correta de arquivos delimitados (CSV) e validação de tipos de dados.
* **Análise Descritiva**: Construção de Tabelas Dinâmicas e Gráficos Exploratórios para identificar padrões rápidos.

---

## Materiais Disponíveis

* **Aula 2 - Analise de Dados - Excel para Análise de Dados**: Conteúdo interativo e guias práticos do software.
* **ATIVIDADE_2**: Pasta contendo os desafios propostos de análise e relatórios.
* **ArquivoPDF**: Guia de referências, instruções detalhadas e fundamentação da atividade.
