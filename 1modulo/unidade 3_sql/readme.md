# Unidade 3: Fundamentos de SQL e Banco Local com DuckDB/SQLite

Esta unidade é focada na manipulação de dados estruturados e na criação de regras de negócio complexas via linguagem SQL.

---

## Escopo da Unidade

* **Manipulação de Dados**: Execução de queries estruturadas diretamente em bases locais eficientes.
* **Construção de Indicadores**:
  * Consultas básicas e filtros condicionais com `SELECT` e `WHERE`.
  * Agregações estatísticas e visões agregadas utilizando `GROUP BY`.
  * Criação lógica da flag `acidente_fatal` através da cláusula `CASE WHEN`.
  * Geração de rankings geográficos analíticos por UF, Rodovia (BR) e Município.
  * Análises temporais complexas e scripts SQL 100% documentados.

---

## Materiais Disponíveis

* **Aula 3 - Analise de Dados - SQL com DuckDB ou SQLite**: Conteúdo interativo e configuração do ambiente de banco de dados local.
* **Scripts SQL**: Repositório de arquivos `.sql` documentados com o passo a passo das consultas analíticas realizadas.
